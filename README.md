<h1>Customer Churn Analysis</h1>







<h2>Description</h2>

This project analyzes customer behavior for a telecom operator to predict which customers are likely to churn. By identifying at-risk customers early, the company can offer targeted incentives, personalized promotions, and improved service to retain them.



The marketing team provided client demographics, usage patterns, contract details, and service information. The goal is to build a predictive model that accurately identifies customers most likely to leave.





<h2>Project Overview</h2>



<b>Data preprocessing:</b> handling missing values, encoding categorical features, and scaling numerical features

<b>Exploratory Data Analysis:</b> examining churn rates, patterns, and important correlations

<b>Feature engineering:</b> creating new features to improve model performance

<b>Model training \& evaluation:</b> training multiple ML models and comparing their performance

<b>Final conclusion:</b> evaluating results and selecting the best-performing model



<h2>Models Trained</h2>



- Logistic Regression

- Random Forest

- Decision Trees

- Gradient Boosting Classifier

- XGBoost

- LightGBM
